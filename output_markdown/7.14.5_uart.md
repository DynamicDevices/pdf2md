### Figure 7-2: SSI Timing for MICROWIRE Frame Format (FRF = 10), Single Transfer

This timing diagram illustrates the Synchronous Serial Interface (SSI) communication using the MICROWIRE frame format for a single transfer.

*   **Signals Shown:**
    *   `SSIClk`: The serial clock signal. It is shown as a continuous oscillating waveform when active.
    *   `SSIFss`: The frame select/sync signal. It is active low. The transfer begins when `SSIFss` goes low and ends when it returns high.
    *   `SSITx`: The transmit data line. It shows an 8-bit control word being sent, starting with the Most Significant Bit (MSB) and ending with the Least Significant Bit (LSB).
    *   `SSIRx`: The receive data line. After a delay (indicated by a '0' bit period), it shows 4 to 16 bits of output data being received, also from MSB to LSB.
*   **Timing Parameters:**
    *   `S1`: The time between consecutive rising and falling edges of `SSIClk` (half a clock period).
    *   `S2`: The setup time from the falling edge of `SSIFss` to the first rising edge of `SSIClk`.
    *   `S3`: The setup time from the falling edge of `SSIFss` to the first falling edge of `SSIClk`.
*   **Data Transfer:** The master initiates the transfer by asserting `SSIFss` (pulling it low). It then sends an 8-bit control word on `SSITx`. Following this, the slave responds by sending 4 to 16 bits of data on `SSIRx`.

### Figure 7-3: SSI Timing for SPI Frame Format (FRF = 00), With SPH = 1

This timing diagram shows the SSI communication using the SPI frame format, specifically with the clock phase (SPH) set to 1.

*   **Signals Shown:**
    *   `SSIClk (SPO = 0)`: The serial clock with polarity 0 (idle state is low).
    *   `SSIClk (SPO = 1)`: The serial clock with polarity 1 (idle state is high).
    *   `SSITx (Master)`: The master's transmit data line, showing data from MSB to LSB.
    *   `SSIRx (Slave)`: The slave's receive data line, showing data from MSB to LSB. The first bit is shown as indeterminate.
    *   `SSIFss`: The frame select signal, which is active low for the duration of the transfer.
*   **Timing Parameters (SPH = 1):** With SPH = 1, data is captured on the second clock edge of each period.
    *   `S1`: The full period of the `SSIClk`.
    *   `S2`: The time from the falling edge of `SSIFss` to the first clock edge.
    *   `S3`: The time from the last clock edge to the rising edge of `SSIFss`.
*   **Data Transfer:** This diagram illustrates a standard full-duplex SPI transfer. The master sends data on `SSITx` and simultaneously receives data from the slave on `SSIRx`. The transfer is framed by the `SSIFss` signal. Two clock polarity options (`SPO=0` and `SPO=1`) are shown.
