**Figure 7-1: SSI Timing for TI Frame Format (FRF = 01), Single Transfer Timing Measurement**

This timing diagram illustrates the signal relationships for a single data transfer using the Synchronous Serial Interface (SSI) in TI frame format.

*   **Signals Shown:**
    *   **SSIClk:** The serial clock signal, which synchronizes the data transfer.
    *   **SSIFss:** The frame select signal (also known as slave select or chip select). It is active low.
    *   **SSITx / SSIRx:** The transmit/receive data line.

*   **Timing Parameters:**
    *   **S1 (t<sub>clk_per</sub>):** Represents the complete cycle time of the SSIClk signal.
    *   **S2 (t<sub>clk_high</sub>):** Represents the duration for which the SSIClk signal is high.
    *   **S3 (t<sub>clk_low</sub>):** Represents the duration for which the SSIClk signal is low.

*   **Transfer Sequence:**
    1.  The `SSIFss` signal goes low to initiate the data transfer.
    2.  The `SSIClk` starts toggling.
    3.  Data on the `SSITx / SSIRx` line is transferred serially, one bit per clock cycle. The diagram shows the transfer starting with the Most Significant Bit (MSB) and ending with the Least Significant Bit (LSB).
    4.  The transfer length is indicated as being "4 to 16 bits".
    5.  After the last bit (LSB) is transferred, the `SSIFss` signal goes high, ending the frame.
