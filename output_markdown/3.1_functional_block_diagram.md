# 3.1 Functional Block Diagram


![Figure 3-1. CC1312R7 Block Diagram](./images/page_3_diagram.png)


**Figure 3-1: CC1312R7 Block Diagram**

This diagram illustrates the high-level architecture of the CC1312R7 wireless microcontroller, showing its main processing cores, memory, peripherals, and RF components. The system is divided into several major functional blocks: Main CPU, RF Core, General Hardware Peripherals, Sensor Interface, and power management.

### Main CPU
The central processing unit responsible for the main application and protocol stack.
*   **Processor:** Arm® Cortex®-M4F, running at 48 MHz.
*   **Memory:**
    *   704KB Flash with 8KB Cache
    *   144KB SRAM with Parity
    *   256KB ROM
*   **Debug:** cJTAG interface.

### RF Core
A dedicated core for handling the Sub-1 GHz radio protocol.
*   **Processor:** Arm® Cortex®-M0.
*   **Radio Components:**
    *   DSP Modem
    *   Digital PLL
    *   ADCs for the radio
*   **Memory:**
    *   16KB SRAM
    *   ROM

### General Hardware Peripherals and Modules
A collection of standard peripherals for general-purpose use.
*   **Timers:** 4× 32-bit Timers
*   **Serial Communication:**
    *   2× SSI (SPI)
    *   I²C and I²S
    *   2× UART
*   **Direct Memory Access:** 32 ch. µDMA
*   **General Purpose I/O:** 31 GPIOs
*   **Security:**
    *   AES-256, SHA2-512
    *   ECC, RSA
    *   TRNG (True Random Number Generator)
*   **System and Monitoring:**
    *   Watchdog Timer
    *   Temperature and Battery Monitor
    *   RTC (Real-Time Clock)

### Sensor Interface
A dedicated set of low-power peripherals for interfacing with external sensors, capable of operating autonomously.
*   **Controller:** ULP Sensor Controller
*   **Analog Peripherals:**
    *   12-bit ADC, 200 ks/s
    *   2× Low-Power Comparator
    *   Constant Current Source
    *   8-bit DAC
    *   Time-to-Digital Converter
*   **Digital Interface:** SPI-I²C Digital Sensor IF
*   **Memory:** 4KB SRAM

### LDO, Clocks, and References
This block manages the power supply and clocking for the entire device.
*   Includes LDOs, clock sources, and voltage references.
*   Features an Optional DC/DC Converter for improved efficiency.
