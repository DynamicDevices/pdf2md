# 3.1 Functional Block Diagram


![Figure 3-1: CC1312R7 Block Diagram](./images/page_3_diagram.png)


**Figure 3-1. CC1312R7 Block Diagram**

The diagram shows the high-level architecture of the CC1312R7 wireless microcontroller, which is organized into several main functional blocks.

### Main CPU
The central processing unit and main application domain.
- **Processor:** Arm® Cortex®-M4F running at 48 MHz.
- **Memory:**
    - 704KB Flash with 8KB Cache
    - 144KB SRAM with Parity
    - 256KB ROM
- **Interface:** cJTAG for programming and debugging.

### RF Core
A dedicated subsystem for handling radio communications.
- **Processor:** Arm® Cortex®-M0.
- **Radio:** Sub-1 GHz transceiver connected to an external antenna.
- **Components:**
    - DSP Modem
    - Digital PLL
    - ADCs for the radio
- **Memory:**
    - 16KB SRAM
    - ROM

### General Hardware Peripherals and Modules
A collection of standard peripherals for communication, timing, and security.
- **Timers/Clocks:**
    - 4× 32-bit Timers
    - Watchdog Timer
    - RTC (Real-Time Clock)
- **Communication Interfaces:**
    - 2× SSI (SPI)
    - I²C and I²S
    - 2× UART
- **General Purpose:**
    - 32 ch. µDMA
    - 31 GPIOs
- **Security:**
    - AES-256, SHA2-512
    - ECC, RSA
    - TRNG (True Random Number Generator)
- **Monitoring:**
    - Temperature and Battery Monitor

### Sensor Interface
A dedicated block for interfacing with and controlling external sensors, capable of autonomous operation.
- **ULP Sensor Controller:** An autonomous processor for ultra-low-power sensor operations.
- **Analog Components:**
    - 2x Low-Power Comparator
    - 12-bit ADC, 200 ks/s
    - Constant Current Source
    - 8-bit DAC
    - Time-to-Digital Converter
- **Digital Interface:**
    - SPI-I²C Digital Sensor IF
- **Memory:**
    - 4KB SRAM

### Power Management
This block handles power regulation and clock generation for the entire device.
- LDO, Clocks, and References
- Optional DC/DC Converter
